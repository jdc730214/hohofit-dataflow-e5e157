# 禾青心訓：App 與後台資料關聯圖

這份互動式網頁說明禾青心訓 App 與後台之間的資料流向：每個畫面或數值從哪裡來、怎麼計算、多久一次、存在雲端哪裡，以及在後台哪一頁看得到。

## 怎麼看

直接開啟網頁版（GitHub Pages）：

**https://jdc730214.github.io/hohofit-dataflow-e5e157/**

- 點任何一個畫面縮圖、標題或數值，會亮出它的來源與去向，右側顯示實際截圖與說明
- 截圖上的青色閃爍框標示該項目的位置，琥珀色框標示待修的地方
- 上方 1 到 7 的流程按鈕可照順序看完整流程
- 頁尾列出 11/3、11/8 討論中尚未完成的項目
- 手機、平板、電腦都可以看

## 怎麼討論

請到本頁上方的 **Issues** 分頁，按 **New issue**，選「討論項目」範本填寫。

- 一個問題開一則，方便追蹤處理進度
- 請註明是圖上的哪一個項目，例如「區間下限／上限」
- 需要附圖時，可直接把截圖拖進文字框

留言需要 GitHub 帳號，可在 https://github.com/signup 免費註冊。
